# Analizador-visual-de-posturas-deportivas

## Ejecución del programa

Para ejecutar el programa según el ejercicio, utiliza el siguiente comando:

```bash
python main.py -type <tipo_ejercicio> -source <ruta_video>
```

Por ejemplo, para ejecutar el análisis de una plancha:

```bash
python main.py -type plank -source videos/plank.mp4
```

## Análisis en tiempo real

Para realizar el análisis en tiempo real utilizando la cámara, utiliza el siguiente comando:

```bash
python main.py -type <tipo_ejercicio> -source 0
```
